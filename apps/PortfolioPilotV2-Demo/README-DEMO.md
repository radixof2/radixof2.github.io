# PortfolioPilot Static Demo

This is a fictional, read-only simulation of PortfolioPilot. It does not
connect to Schwab, access the network, use financial credentials, or submit
orders. Prices, positions, trades, history, recommendations, and roll candidates
are synthetic and are not financial advice.

## Run the demo

1. Unzip the archive.
2. Double-click `index.html`.

No Python installation, command script, local server, certificate, OAuth setup,
or brokerage account is required. Client-side JavaScript adjusts the displayed
scenario dates to the current New York market date each time the page opens.

The package contains only static HTML, CSS, JavaScript, the generated fictional
dashboard model, this README, and the project license.
